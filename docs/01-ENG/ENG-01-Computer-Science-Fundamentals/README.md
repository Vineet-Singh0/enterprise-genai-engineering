## Welcome

Computer Science Fundamentals is the foundation of every software engineering discipline.

Whether you build web applications, AI systems, operating systems, cloud platforms, databases, or Large Language Models (LLMs), every program eventually runs on a computer.

Understanding **how a computer executes software** helps you become a better engineer. Instead of memorizing technologies, you learn the principles that remain useful even as tools and frameworks change.

This module builds that foundation.

---

## Learning Objectives

By the end of this module, you should be able to:

* Explain how hardware and software work together.
* Describe the major components of a computer.
* Understand how a CPU executes instructions.
* Explain the purpose of different types of memory.
* Understand the complete lifecycle of a running program.
* Describe the responsibilities of an operating system.
* Explain the difference between processes and threads.
* Understand how filesystems organize data.
* Explain how computers communicate with storage and external devices through Input/Output (I/O).

## Why This Module Exists

Think about a simple Python program:

```python
print("Hello, World!")
```

It looks simple.

But behind the scenes:

* The operating system starts your program.
* Memory is allocated.
* The CPU fetches instructions.
* The CPU executes those instructions.
* Characters are written to the terminal.
* The operating system releases resources after the program finishes.

Understanding these hidden steps helps you:

* Debug problems faster.
* Write more efficient software.
* Understand performance bottlenecks.
* Learn advanced topics more easily.
* Build production-grade systems with confidence.
