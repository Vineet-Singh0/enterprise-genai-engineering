# ENG-02 — Programming Foundations

**Domain:** Engineering Foundations (ENG)  
**Module ID:** ENG-02  
**Purpose:** Build a strong programming foundation by understanding how software is designed, structured, executed, and maintained. The module emphasizes engineering thinking over language memorization and uses Python as the reference language for practical examples.

---

## Overview

Programming Foundations teaches the concepts every later domain assumes: how programs represent data, control execution, organize code into reusable units, handle failure, and stay maintainable as systems grow.

Python is the working language for examples. The goal is not to memorize Python syntax, but to develop durable programming judgment that transfers to other languages and to AI-system codebases.

## Learning Objectives

By the end of ENG-02, you should be able to:

1. Explain how programs represent and transform data.
2. Use control flow, functions, and modules to structure readable code.
3. Choose appropriate data structures and collection patterns for a problem.
4. Apply object-oriented and functional techniques where they clarify design.
5. Handle errors deliberately and organize projects with clear package boundaries.
6. Use virtual environments and dependency management for reproducible work.
7. Apply practical Python engineering practices that keep code reviewable and maintainable.

## Prerequisites

- Completion of, or comfort with, [ENG-01 — Computer Science Fundamentals](../ENG-01-Computer-Science-Fundamentals/README.md)
- Basic computer usage and willingness to write and run small programs

No prior professional programming experience is required.

## How to Study This Module

1. Read each lesson for the engineering idea first, then the Python examples.
2. Type and run the examples; modify them until the behavior is clear.
3. Use interview and revision sections to check understanding, not as a substitute for reading.
4. Prefer clear structure and naming over clever one-liners.
