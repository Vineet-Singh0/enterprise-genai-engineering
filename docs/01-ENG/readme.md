# Engineering Foundations (ENG)

Welcome to the **Engineering Foundations (ENG)** domain of the Enterprise GenAI Engineering curriculum.

This domain provides the software engineering and computer science foundations required for every subsequent domain in the curriculum.

Before building AI systems, engineers must first understand how computers execute software, how applications are designed, how operating systems manage resources, how software communicates over networks, and how professional software is developed and maintained.

The concepts in this domain form the foundation upon which the entire curriculum is built.

---

## Domain Objective

The objective of Engineering Foundations is to develop the core engineering knowledge required to design, build, debug, and maintain modern software systems.

After completing this domain, you will understand:

- How computers execute programs
- How software interacts with hardware
- Professional programming practices
- Software engineering principles
- Linux fundamentals
- Computer networking
- Database fundamentals
- Development workflows
- Software quality practices
- Concurrency fundamentals

These concepts are essential prerequisites for AI Engineering, LLM Engineering, Production Systems, and Enterprise AI.

---

## Learning Outcomes

By the end of this domain, you should be able to:

- Explain how modern computer systems work.
- Write clean and maintainable software.
- Understand software architecture fundamentals.
- Work effectively with Git and collaborative development workflows.
- Use Linux confidently for software development.
- Understand how applications communicate across networks.
- Design and query relational databases.
- Apply testing and debugging techniques.
- Organize professional software projects.
- Understand concurrency and asynchronous execution.
